# 安全与性能防御

默认开启的防线：沙箱、CSP、路径稳健、体积门禁，劣化在 CI 阶段就被拦下。

## 收录的解法

| 解法 | 一句话说明 | 状态 |
| --- | --- | --- |
| 渲染进程沙箱 | contextIsolation + sandbox，网页代码碰不到 Node 能力 | 待写 |
| 内容与外链管控 | CSP + 外链白名单，能加载什么、能跳去哪里都是显式的 | 待写 |
| 路径稳健性 | 不依赖 process.cwd()，相对模块自身定位资源，快捷方式启动不找错目录 | 待写 |
| 体积与加载管控 | 第三方依赖分包 + asar 体积门禁 | 待写 |
