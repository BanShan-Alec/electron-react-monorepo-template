# 架构组织

主进程与渲染进程各自的代码组织方式：加功能是加模块、加目录，不是改祖传代码。

## 收录的解法

| 解法 | 一句话说明 | 状态 |
| --- | --- | --- |
| 多窗口物理入口 | MPA 双入口，更新窗口独立成页不背主应用包袱 | 待写 |
| 领域驱动组织 | features/ 按功能分目录，删功能就是删目录 | 待写 |
| 组件编写模板 | 一组件一文件夹 + 固定代码分区，人和 AI 写出来一个样 | 待写 |
| 生命周期解耦 | ModuleRunner 微内核，原生事件拆成可插拔模块 | 待写 |
| 分层纪律 | Controller/Service 分离，业务代码可脱离 Electron 单测 | 待写 |
