# 快速上手（Getting Started）

本站没有阅读顺序要求——按需检索、即查即走。三种典型用法：

::::steps

### 按维度浏览

左侧侧栏把 47 个解法按 9 个维度分组（工程化基座、开发体验、架构组织……），点击组名展开。适合刚接手本仓库、想系统了解工程决策的模板使用者。

### 按关键词搜索

按 <kbd>Ctrl</kbd>+<kbd>K</kbd>（或点右上角搜索框）输入问题关键词：「更新」「托盘」「白屏」「asar」……搜索覆盖全部解法页正文。适合带着具体问题来的踩坑者。

### 进解法页抄源码

每个解法页的三段式是固定的：**要解决的坑 → 本仓库的解法 → 怎么抄**。「解法」小节里的每段代码都附 `→ 源码：` 链接，直达仓库中对应文件；「怎么抄」给出在你自己项目里落地的步骤与注意点。

::::
