# 什么是解决方案合集（Introduction）

这不是一份「如何用 Electron」的教程，而是一份**踩过坑之后的解法目录**：每个条目对应 Electron 桌面应用开发中一个真实会踩的坑——自动更新、单实例锁、沙箱、崩溃上报、体积失控……以及本仓库中经过发版验证的真实实现。

## 为什么是「发版级」解法

网上搜到的 Electron 解法大多是碎片化的：一段代码、一句提示、某个 issue 里的 workaround。它们通常：

- 没有经过真实打包与发版验证——开发态能跑，装进用户机器就出问题
- 不成体系——解决了 A 坑引出 B 坑，没人告诉你两者的关联
- 没有可抄的完整实现——思路有了，代码还得自己拼

本站的每个解法页都长一个样：**要解决的坑 → 本仓库的解法（附真实源码链接）→ 怎么抄**。「发版级」的意思是：这段代码不只在开发环境跑通，而是随本仓库的安装包发出去、被真实更新过若干个版本。

## 双读者

**模板使用者**：clone 仓库后按维度浏览，理解每个工程决策「为什么这么定」，改造成自己的应用时心里有底。

**踩坑的人**：遇到具体问题按关键词搜（右上角搜索框），直接进对应解法页抄源码，不需要通读全站。

## 与模板仓库的关系

本站与 [electron-react-monorepo-template](https://github.com/BanShan-Alec/electron-react-monorepo-template) 是同一个仓库的两面：文档里出现的每一段源码都能在仓库里找到对应文件，仓库里的每个工程决策都在文档里有一页解释。拿模板的人按图索骥，踩坑的人按问题搜解法。
