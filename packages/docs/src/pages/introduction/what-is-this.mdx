# 什么是解决方案合集（Introduction）

这不是一份「如何写 Electron Hello World」的新手入门教程，而是一份**专为严肃桌面应用设计的工程解法速查目录**。

与社区常见的纯脚手架（如 `electron-vite`、`electron-forge` 等仅提供打包骨架）不同，本仓库不仅打通了构建流程，更沉淀了一整套生产级桌面应用必不可少的**工程规范与业务基座**——从 Windows WCO 自定义标题栏、严格 CSP 沙箱安全，到 Base64URL 单向环境变量管道、跨进程 W3C 日志链路追踪与分包体积硬性门禁。

## 为什么称作「工业级验证」解法

网络碎片化代码通常只在本地 `npm run dev` 玩具环境跑通，一进打包与真实用户系统便漏洞百出。本仓库解法均经过以下刚性门禁验证：

- **全平台真实打包**：在 Windows / macOS / Linux 真实矩阵上完成安装包物理打包（NSIS / DMG / AppImage）。
- **产物冒烟与协调器校验**：构建后无头驱动真实 Electron 实例，校验骨架屏到 React 渲染协调器的揭幕时序，拒绝空壳 `#root` 假阳性。
- **完整升级与安全基线**：贯穿 GitHub Releases 自动更新签名、严格 CSP 策略、上下文隔离（contextIsolation）及主进程 Node 白名单。

## 三类读者使用姿势

- **模板使用者**：Clone 仓库后按维度查阅，理解核心工程决策背后的取舍，在此基座上安全扩展业务。
- **踩坑查阅者**：直接通过右上角搜索框检索关键词（如「单实例」「CSP」「日志」「asar」），直奔对应条目的避坑清单与源码链接。
- **AI 协作者**：全站配备 `llms.txt` / `llms-full.txt` 与纯 Markdown 路由，各包均有独立的 `AGENTS.md` 边界规约，适合大模型按需精确切片召回。
