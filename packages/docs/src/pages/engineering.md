# 工程化基座

多包工程的底座：让「多包不漂移、配置不复制、依赖不越界」由工具保证，而不是靠人肉约定。

## 收录的解法

| 解法 | 一句话说明 | 状态 |
| --- | --- | --- |
| Monorepo 工程治理 | pnpm workspaces 多包物理隔离、依赖版本统一管理 | 待写 |
| 依赖边界管控 | verify 脚本 + CI 门禁，根目录依赖白名单 | 待写 |
| 配置继承体系 | @app/tsconfig 继承包，编译配置一处定义、各处继承 | 待写 |
| 环境变量管理 | 根目录 .env 单一事实源，运行时注入渲染进程 | 待写 |
| 格式化与检查 | Biome 单工具管格式、检查、import 排序 | 待写 |
| 提交信息规范 | commitlint 强制 Conventional Commits + 中文描述 | 待写 |
