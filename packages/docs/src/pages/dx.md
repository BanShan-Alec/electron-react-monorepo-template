# 开发体验

一条命令拉起整套开发环境；端口冲突、远程调试、进程清理这些天天碰的琐事全部交给脚本。

## 收录的解法

| 解法 | 一句话说明 | 状态 |
| --- | --- | --- |
| 开发即生产 | 一条 `pnpm start` 同时拉起 Vite DevServer 与 Electron，双进程热重载 | 待写 |
| 端口冲突自治 | 启动前端口预检，被占用时提示并协助处理 | 待写 |
| 远程调试开箱即用 | 开发模式自动开放 CDP 调试端口，断点与性能面板直连 | 待写 |
| 退出无残留 | 关闭开发终端连带清理 Electron 进程树，不留僵尸实例 | 待写 |
