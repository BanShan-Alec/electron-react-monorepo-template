### 常用一键命令：
- **拉取最新审查看板**：`pnpm pr-review pull`
- **触发增量审查**：`pnpm pr-review trigger`
- **创建 PR**：`pnpm pr-review create`
- **查看状态**：`pnpm pr-review status`
- **安全合并**：`pnpm pr-review merge`
